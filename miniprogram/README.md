# 微信小程序套壳（模板）

这个文件夹是一个**最小可用的小程序模板**：首页四个按钮，点进去用 `web-view` 打开现有的「顺势」网页。

> 先说清楚：截至 2025 年，**个人主体的小程序不能使用 `web-view`，也不能配置业务域名**（微信官方限制）。这个模板只有在以下条件都满足时才能发布：
>
> 1. 小程序主体是**企业或组织**（个人主体请勿使用本模板）；
> 2. 有一个**自己名下的、已完成 ICP 备案的 HTTPS 域名**；
> 3. 在微信公众平台「开发管理 → 开发设置 → 业务域名」里配置了这个域名；
> 4. `github.io` 不能直接用作业务域名，需要把网页部署到自己的备案域名（或做反向代理）。
>
> 如果暂时没有这些条件，请先使用 PWA：手机浏览器打开网站 →「添加到主屏幕」，效果接近 App，成本为零。

## 怎么用

1. 用微信开发者工具「导入项目」，选择这个 `miniprogram` 文件夹。
2. 在 `project.config.json` 里把 `appid` 换成你的小程序 AppID。
3. 打开 `config.js`，把 `SITE` 改成你的备案域名，例如：
   ```js
   module.exports = { SITE: 'https://english.example.com/teacher/' };
   ```
   注意结尾要有 `/`，并且该域名下能访问 `index.html`、`student.html`、`teacher.html`、`library.html`。
4. 在微信公众平台配置业务域名，下载校验文件放到网站根目录，确认能通过校验。
5. 真机预览。若提示“不支持打开非业务域名”，就是第 3、4 步没配好，或账号是个人主体。

## 四个入口

| 按钮 | 打开的页面 |
| --- | --- |
| 主页 | `index.html` |
| 学生端 | `student.html` |
| 教师端 | `teacher.html` |
| 组卷工作台 | `library.html` |

## 个人主体想做成“真小程序”怎么办

个人主体不能用 `web-view`，只能把页面**改写成原生小程序**（WXML / WXSS / JS），数据用 `wx.setStorageSync` 存在手机本地，任务码、汇报码的逻辑可以照搬。工作量约等于把现有四个页面重做一遍；而且教育类服务类目可能需要相应资质，提交审核前要先确认类目是否对个人开放。

在没有企业主体和备案域名之前，建议的顺序是：

1. 先用 PWA（已做好，见网站 README）；
2. 在微信里直接分享网页链接，学生点开即用；
3. 等有主体和域名后，再用这个模板套壳，或投入时间做原生版。
