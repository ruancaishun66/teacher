Guide / 使用指南

从一份资料，到一份像样的卷子。

按下面的顺序操作即可。第一次建议先用「载入示例资料」走一遍完整流程，再上传自己的试卷。

1上传资料：Word、PDF、图片都可以

进入「上传资料」，把文件拖进虚线框，或点「选择文件」。支持 .docx、.pdf、.txt、.md、.png、.jpg、.jpeg。一次可以选多份。

  • 有文字层的 PDF 会直接提取文字；扫描版 PDF 和图片会自动走本地 OCR。
  • 入库前会自动清理重复页眉页脚、页码、题库网址、扫描软件水印和符号噪点，生成练习时还会再清一次。清理不彻底时，可在资料编辑里手动删掉那几行。
  • 扫描版现在默认读整本全部页，几百页的整本练习册也能一次入库；页数越多越慢，识别时电脑别休眠。只想先处理其中一段时，到设置里把「扫描 PDF 识别范围」改成「只识别指定页码」，填上从第几页到第几页即可。
  • OCR 是机器识别，题号、引号和易混字母（l/I、0/O）可能出错。入库后点资料卡上的「修改」核对一遍，准确率会高很多。
  • 如果提取出来题号、选项、大题标题粘成一团，点资料卡上的「豆包精排」图标：复制提示词给豆包，让它只调整换行和分段，再把整理稿整段粘回来，系统会按新稿一道一道重新拆题。
  • 旧版 .doc 会完整存档，但不能自动提取文字；用 Word 另存为 .docx 最稳。

2核对分类：题型和年级可以手动改

系统会先看试卷里的部分标题（听力、选择填空、完形填空、阅读理解、五选五、语法填空、书面表达等），再结合题号、选项、空格和文章结构判断题型。综合卷会被拆成多个部分，阅读还会按 A/B/C/D/E 篇拆开。

  • 语法填空、短文填空、短文填词、语篇填空、首字母填空、选词填空已经合并为同一类「语法填空」，不会再因为叫法不同被拆成两个大题；出卷时若原卷写的是「完成句子」「选词填空」或「首字母填空」，大题标题会跟着原卷走，不会一律印成「语法填空」。
  • 识别不准时，点资料卡右侧的铅笔图标，修改题型、年级、标签和正文，保存后会重新拆题。
  • 遇到新的大题叫法（例如「阅读还原」「词汇运用」「看图写话」），豆包精排后会把它记进「设置 → 题型识别库」；以后同类卷子直接就能认出来。也可以手动添加别名。
  • 每道题会自动给出 1–10 级难度，依据包括词汇长度与难度、平均句长、长难句、从句、非谓语、被动语态、空格数量和题型；资料卡和答案区会同时显示对应的 ★–★★★★★ 星级。
  • 系统会从文件名、卷头和正文自动判断初中/高中；也可以在资料库顶部按「初中 / 高中」筛选，或在编辑资料时手动改年级。

3题库：逐题勾选，凑齐再组卷

资料确认入库后，拆好的题目会按题型进入「题库」。这里可以把每一组题、每一道小题都翻出来看，不必先想好整卷要哪些。

  • 顶部能按题型、年级、资料筛选，也能搜题干、选项或资料名；筛选后可以「全选当前」。
  • 单选直接列题干和选项；阅读、完形等共用一篇材料的大题，会先显示篇名或原文开头，下面逐条列小题和选项。勾选任意一题会整组带进候选栏，材料不会拆散。
  • 勾选后底部出现候选栏，显示“几组·几题”；点「生成练习卷」进入排版预览，确认后「存入练习卷」，再去教师端布置。
  • 点「题库存到 U 盘」会按题型分别写入 U 盘「题库」文件夹：一份 JSON 保留完整结构，一份 CSV 可直接用 Excel 打开。

4词汇书：整本上书架，点开再选词

点左侧「词汇书」→「选择词汇书」，可以一次上传整本 .pdf、.docx、.txt 或 .md。几百页的词汇书也能整本读，扫描版会自动走本机 OCR。

  • 平时看到的是书架封面；点开一本书，才会读取并显示全书单词，按每页 60 个翻看，也能搜索单词或释义。
  • 可以勾选本页、全选筛选结果或逐条勾选；候选栏支持导出 CSV / TXT、存到 U 盘「词汇书」，或「带到教师端」自动填入单词任务。
  • 教师端一次单词任务最多带 80 个词；超过时先带前 80 个，其余留在书里分批再选。
  • 词汇书只保存文字和单词，不重复保存原文件；原书请自己留好。换电脑或清理浏览器数据前，先导出备份。

5生成每日练习：一句指令就够

进入「每日练习」，先选「全部 / 初中 / 高中」题库，再在指令框里写年级、题型、数量和难度。指令里写「初中」「高中」「高一」等字眼时，会自动切换到对应题库。例如：

今日练习 单选5道 阅读理解1篇 语法填空1篇 难度5-7 高中 完形填空1篇 阅读理解2篇 难度6 初中 五选五1篇 语法填空1篇 难度5 书面表达1篇 高三 难度7
  • 学段是硬边界：选「初中」时不会拿高中题凑数，反之亦然；某个题型在当前题库里没有时，会明确提示并跳过。
  • 难度可以写单级（难度6）、区间（难度5-7），也可以写「基础 / 中等 / 提高 / 挑战」。
  • 不写题型时，会按当前题库的「单选 + 完形 + 阅读 + 语法 + 作文」默认组合抽取。
  • 生成后会按 A4 试卷版式排版：日期标题、姓名/班级/得分栏、分题型大题、选项表、阅读篇目、作文横线、答案与解析、词汇表和默写表。
  • 点「换一组」会重新抽题；「下载 Word」得到 .doc，可直接打印或继续编辑；「导出 PDF」在打印窗口选择「另存为 PDF」。
  • 新增「长难句」按钮：从本份练习的阅读、完形、五选五中自动挑出完整长句，生成「原句 + 分析横线 + 译文横线」的练习纸，适合做阅读拆解和长难句提炼。
  • 词汇背诵表和默写表会按年级筛词：去掉 the、does 这类基础词，只保留略高于当前水平、且在本份练习里出现的词；一份 59 题的卷子通常收 30–40 个词，不再印成几十页。

6豆包解析与词表：把详细讲解补到范本水平

本地规则能给出答案、考点、难度和基础答题思路，但范本里那种「语篇导读 + 逐项排除 + 长难句分析 + 熟词生义」需要更强的语言模型。工作台用「复制提示词 → 豆包生成 → 粘贴回来」的方式接入豆包，不需要把 API Key 放在网页里。

  1. 生成练习后，点「豆包解析」，再点「复制提示词」。
  2. 把提示词粘贴到豆包，等它输出完整的答案与详解。
  3. 复制豆包的结果，粘贴到弹窗下方的输入框，点「应用到练习」。解析会写进答案区，也会进入 Word / PDF。
  4. 点「豆包词表」同理：提示词已经按你给的要求写好三列表格和默写表格式，豆包返回后粘贴回来即可补齐 KK 音标和语境释义。

工作台不会自动上传你的试卷，也不会保存豆包账号信息。所有复制和粘贴都在本机完成。

7词汇表与默写表：每次生成都会一起出

生成练习时，系统会从文章和所有选项中按出现顺序抽取单词，去重后生成：

  • 词汇背诵表：三列「英文 / KK 音标 / 中文」，短语和固定搭配单独一张表。
  • 默写表：第一部分英译英，第二部分英译中；每部分再分单个词汇和短语词组；每行两组，四列「参考词 / 默写 / 参考词 / 默写」。
  • 点「词汇表」或「默写表」可以单独下载，方便只发词表而不发整张卷子。
  • 本地词库没有收录的词，音标或中文会显示「—」。用「豆包词表」粘贴回来的结果会覆盖并补齐。

8保存、备份与换设备

  • 资料只保存在当前浏览器里，不会上传到任何网站或服务器。
  • 换电脑、换浏览器、清理浏览器数据，资料都会消失。请在「设置」里每周导出一次 ZIP 备份。
  • 「设置 → U 盘工作区」可以把常插着的 U 盘设为中转站：选中一次后，之后下载的 Word 和导出的备份会自动复制一份到 U 盘；也可以点「备份到 U 盘」立刻存一份。U 盘没插时不影响正常使用。
  • 导入备份会覆盖当前资料库，操作前会再次确认。
  • 手机端同样可以使用：上传、生成、预览、下载都适配了窄屏；表格和长卷子建议横屏或下载后查看。
  • 如果浏览器提示存储空间不足，先导出备份，再删除不再使用的资料；也可以点「申请长期保存」降低被自动清理的概率。

9常见问题

  • 扫描 PDF 识别很慢？ OCR 在浏览器里跑，第一页要加载语言包。默认读整本全部页；赶时间时到「设置 → 扫描 PDF 识别范围」选「只识别指定页码」，先处理需要的那一段。
  • 题目被拆错？ 先点资料卡上的「豆包精排」，让豆包只整理换行和分段；实在不行再打开资料编辑，手动把正文整理成「题号 + 题干 + 选项」，保存后会重新拆题。
  • 豆包精排会改题目内容吗？ 提示词明确要求只动换行和分段，不改写、不增删。应用后仍建议扫一眼；原始文件一直保留，可随时下载。
  • 答案区显示「—」？ 说明原资料没有附答案，或答案不在同一份文件里。用「豆包解析」补齐即可。
  • Word 打开后版式有偏差？ .doc 是 HTML 兼容格式，Word 会按自己的规则重排。打印前在 Word 里检查分页；需要完全固定的版式时，用「导出 PDF」。
  • 能自动调用豆包 API 吗？ 当前版本故意不把 API Key 写进静态网页，避免泄露。使用复制/粘贴工作流最安全；如果你之后有自己的服务器，可以再接 API。
