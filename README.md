## 主页：从阳光沙滩走进深海

主页现在的视觉主题叫「渐深入海」：整页从上往下，像从岸边一步一步走进海里，颜色逐渐加深。

- **阳光沙滩（首屏）**：暖白与米沙色打底，右上角是一轮暖橙色的初阳；首屏底部是一层层浅青色的海浪。
- **海岸浅海（教学特色）**：沙色过渡到浅青绿，像刚没过脚踝的海水，一条细浪线把沙滩与海水分开。
- **波光粼粼（关于我）**：水色变得更清透，海面浮着柔和的日光碎影，白色浪光会缓慢移动。
- **下潜过渡**：在「关于我」和「教学方式」之间，有一段带 5 m / 20 m / 40 m 深度刻度的过渡带，几层波纹向下变暗，中间写着「向更深处，海会安静下来」。过渡带现在拉长到约 244–430 px，水色分成九段慢慢下沉；「教学方式」的开头也留出一片深水，因此不会滚到第三屏就突然变黑。
- **深海幽静（教学方式与页脚）**：深蓝绿的海水、细小的光点，像潜到安静的海底；页脚的微信卡片像一盏暖灯。
- **每一层都有自己的海族**：沙滩层是扇贝和一枚远处海胆，海岸层有一小群鱼和寄居蟹，中层有一条鲨鱼，下潜段漂着两只水母和鲸影，深海里有巨型乌贼和鲸鱼。它们不是贴上去的图标：改成「淡填充 + 细线」的剪影，边缘用渐变蒙版融进海水，再按深度加一点模糊和大气透视；位置刻意放大、裁切到画面外，配合 24–68 秒一圈的极慢漂移，让它们像从水里浮出来的影子。排布保持稀疏，越往深处越大、越淡。手机上会换一套位置和尺寸，并隐藏页脚鲸鱼，避免挡住文字。
- **顶栏会跟着变深**：滚到深海区域时，顶部导航自动从暖白变成深色；回到浅色区域又变回来。

顶栏左侧换成了中英字标：中心「顺势」用毛笔书法体（马善政毛笔楷书，只把用到的 14 个字做成约 6 KB 的字体子集内嵌，手机没装行楷也能显示），外面一圈椭圆印章，上弧 `ENGLISH`、下弧 `SHUNSHI`。中文压住阵脚，英文只做环形点缀；整体像一枚盖在水面上的印章，带一点侠气。原来的「英语教学 × 心理视角」从顶栏移走，页面标题和说明里仍保留这层定位。

标志仍是水滴/地图别针，里面是展翅的凤凰、初阳与浪头。这次把凤凰改成了从暖橙、朱红到深红的渐变：红色与海水的青蓝在色彩学里接近互补色，暖色向前、冷色后退，小尺寸下也更醒目，同时保留「丹凤朝阳」的传统意味。

学生端和教师端保持浅海初阳的浅色界面：暖白卡片、浅蓝边框、珊瑚色按钮和金色点缀；等级、经验、打卡、任务、徽章这些游戏化机制全部保留，只是不再用黑红底色。

这套风格不靠堆装饰，重点是让人一眼感到：这个老师做的是有方向、有节奏的一对一英语教学。

### 学习心得：只有教师端能编辑

主页只负责展示，学生端没有编辑入口。完整流程是「教师端写草稿 → 本地预览 → 导出数据文件 → 发布上线」：

1. 打开教师端，进「心得」页。
2. 点「新增心得」，写标题、日期、摘要、标签和正文；也可以编辑、排序、删除已有心得。保存后先存在这台电脑的教师端浏览器里，不会立刻公开。
3. 点「本地预览」，会在同一浏览器打开 `index.html?insights=preview`，看到主页实际效果。这个预览只有你自己的电脑能看到。
4. 确认后点「导出 insights.js」，文件会下载到「下载」文件夹。
5. 点「复制发布说明」，把那段话发给 Claude Code；或者直接说「我在教师端更新了心得，帮我发布」。Claude Code 会用新文件覆盖项目里的 `insights.js`，同步 U 盘源码，再按 GitHub API 流程发布。
6. 上线后刷新主页，确认「学习心得」卡显示最新内容。

写作格式很简单：空行分段，`##` 小标题，`-` 列表，`**加粗**`，`>` 引用。正文里的 HTML 会被当成普通文字，不会执行。

> 心得是公开内容，请不要写学生姓名、成绩、学校班级等隐私信息。学生档案、成绩和资料库仍然只留在本机，不会因为发布心得而上云。

## 顺势学习平台：一人一号怎么运转

这是一套**本机优先**的轻量平台：没有服务器，也没有云端账号系统。所谓“一人一号”，是老师在自己的教师端里为每个学生建立档案（姓名、学号、年级、初始密码），再由学生用自己的设备建档。平台用“开通码 / 任务码 / 汇报码”在三台设备之间传递信息。

### 第一次：老师建学生档案

1. 打开教师端，第一次先设教师密码（6–16 位字母或数字）。以后每次打开都要输入，防止别人碰你的电脑。
2. 进「学生」页，点「添加学生」，填姓名、学号（3–24 位大写字母、数字、下划线或短横线）、年级和初始密码（4–12 位字母或数字）。
3. 点学生卡片上的「开通码」，复制 `SS1.…` 开头的一长串代码，发给学生。
4. 学生打开学生端，点页面中间最大的「粘贴老师的开通码」，把整段代码粘进去，点「带入资料」。
5. 学生确认姓名和年级，把绿色框里的登录密码记下来，再点「确认信息，创建档案」。密码由开通码带入，不需要改；改了对不上老师的记录。这台设备以后就记住他了。

### 学生第一次进来会看到什么

- 页面只突出一个主按钮：「粘贴老师的开通码」。这是推荐路径，姓名、学号、年级、密码都会自动填好。
- 如果老师暂时没发开通码，点下方「手动填写资料」才会展开姓名、学号、年级、密码。自己随便填的学号和老师那边对不上，会收不到任务，所以非必要不要走这条路。
- 右上角始终有一个「? 怎么用」按钮，点开是 7 步图文说明。学生忘了下一步，点它就行，不用来问你。第 5 步专门讲单词打卡后怎么养「小潮獭」。
- 已经有档案的学生，页面会直接显示登录框；换手机或换浏览器时点「恢复档案」，粘贴之前的汇报码和密码即可。
- 登录框默认勾选「记住密码」，密码只存在这台设备，退出后再打开点一下就能进入；公共电脑可以取消勾选。
- 忘记密码时，用老师发的「重置码」找回：登录页 →「用老师的重置码找回」→ 粘贴 → 自动进入。等级、任务、宠物都保留。老师端学生卡片和详情页都有「重置密码」按钮；老师也可以在「编辑 / 密码」里点「显示」核对现有密码。
- 老师端学生卡片和详情页都有「删除」按钮；学生不续费或不用了，可以直接删除本机记录。

### 每次：老师下发任务

1. 先在教师工作台里组好卷，点「保存到资料库」。
2. 回教师端「任务」页，点「布置任务」，选一张练习卷、选学生、设截止日期和经验值。
3. 平台会为**每个学生单独生成一条任务码**（任务码绑定该学生的学号，别人导入无效）。把对应任务码发给对应学生。
4. 学生打开学生端，点「导入任务码」，粘贴后即可答题。选择题自动判分，作文按完成度计入写作属性；提交后获得经验值，可能升级并获得徽章。

### 每周：一次生成七天任务（不用每天发）

教师端顶部新增「周计划」页，适合“一周布置一次、系统自动拆”的用法。

1. 选“这周从哪天开始”，勾选一周要用的练习卷（可多选）。如果想让中间几天背单词，再选一份已发布的单词任务；系统会把第 2 / 4 / 6 天换成单词闯关，其余 4 天练题。
2. 在「学生与难度」里给每个学生调 1–10 档。低档每日题量少、偏基础；高档题量多、难度高。点 − / ＋ 会立刻保存，下次生成和自动调整都按这个档位。
3. 点「生成本周任务码」。系统按每位学生的档位，把题量拆成 7 天，并为每人生成一份独立的周计划码。把对应的一份发给对应学生即可，不需要每天再发任务。
4. 学生导入周计划码后，先解锁第 1 天。完成当天任务后，第 2 天自动解锁；也可以点「多学一天」提前解锁下一天。中途关掉页面、第二天再回来，已经填的答案和进度都保留。
5. 每次导入学生汇报后，系统会取最近 5 次有分数的任务，自动微调该学生的难度档：平均分低于 62，或单次低于 45，会降一档先把基础稳住；平均分 90 以上且每次都不低于 80、答题信号正常，会升一档。调整记录在学生的「难度变化」里，下一次生成周计划时生效。

> 周计划的拆分、难度匹配和自动调整都在本机计算，不调用 AI，不产生费用。

### 周备课：把一周打卡变成周末这节课

教师端「周备课」页读取本机已有的打卡和汇报，按一周聚合，生成一页能直接上课的建议：

- **规则版（默认，不花钱）**：统计本周有学习的人数、出勤率、完成任务数、单词一次答对率、语法错题；自动挑出最需要补的语法日和 8 个高频错词；给出 90 分钟课堂流程（词汇唤醒 → 语法微课 → 句型操练 → 读写输出 → 复盘作业）、语法微课卡、4 道当堂练习和作业。
- **学生逐个建议**：每位学生一行，写清本周打卡几天、完成几个任务、单词正确率和下节课先做什么。没有汇报的学生会提示先收汇报码。
- **打印 / 存 PDF**：打开打印版，浏览器里选“另存为 PDF”。
- **下载学生讲义**：只含词汇、语法、练习和参考答案，不含姓名和成绩，可以直接发学生。
- **AI 润色（可选）**：只发送匿名汇总（人数、正确率、错词、语法错点），不含姓名和学号；点一次才调用一次，约 300–500 tokens，页面显示输入 / 输出和费用。规则版已经能上课，不用 AI 不影响。

### 体验卡：正式学生和体验学生分开

添加学生时可以选择账户类型：

- **正式学生**：长期使用，不受体验期限制。
- **体验学生**：默认 3 天（可改 1–30 天）。到期后学生端会锁住答题和打卡，只保留查看与“申请延长”入口；学习记录、连击和宠物都不会丢。
- 学生点“申请延长”会生成一段申请码。老师在「体验卡」页粘贴申请码，选延长天数，生成延长码发回；也可以在体验学生名单里直接生成延长码，或生成“转正码”把账户升级为正式学生。
- 学生导入延长码或转正码后立即恢复；转正后不再显示到期提醒。

### 学生回传学习情况

1. 学生在学生端点「生成汇报码」，把 `SS1.…` 汇报码发给老师。
2. 老师在教师端点「导入汇报」，粘贴汇报码。平台会核对学号、密码和汇报码签名，通过后更新该学生的任务记录、五维属性和认知画像。
3. 进学生详情页，可以看雷达图、任务历史、错题分布、最近发展区、教学建议。AI 分析有两条路：① 免费路线，复制“AI 分析提示词”到豆包 / DeepSeek / 通义，再把结果粘回来保存；② 直连路线，在「设置 → AI 直连」保存 DeepSeek Key 后点“一键分析”，只有点击并确认才调用，Key 只存本机、不进备份码。两条路的提示词都会隐去学生姓名，也不含试卷原文；教师备注如含真实姓名，粘贴前请自行替换。
4. 画像分析框架参考 Bloom 认知目标分类、Zimmerman 自我调节学习、Vygotsky 最近发展区和 Black & Wiliam 形成性评价；样本少于 10 题时只作方向性参考。

### 每日汇报码与教师端每日看板

学生每天做完后，在汇报区选「今日汇报」，生成当天的小汇报码发给老师；周末也可以选「本周汇报」，一次带回整周。老师端「单词打卡」页的「每日看板」按周显示：绿色＝当天已完成，黄色＝部分完成，灰色＝没有记录；可以切换上一周 / 本周 / 下一周，点学生进入详情看每题作答。这样不用每天催整周汇报，也不会把整周数据拆散。

### 疑似乱点：本机信号，不靠 AI

学生每次提交任务时，学生端会在本机算一个 0–100 的“答题信号分”，不需要联网，也不产生 AI 费用。它会看：

- 每题平均用时是否短得不正常；
- 同一道题是否反复改答案；
- 答题过程中是否多次离开页面；
- 是否总选同一个选项；
- 正确率是否接近四选一的瞎猜水平。

信号分低于 55 时，教师端总览的待办会提示“某学生有疑似乱选信号”；学生详情里也会显示黄色标记和具体原因。它只是提醒，不会自动判作弊；确实存在“题太简单做得快”或“网络卡顿丢焦点”的情况，建议结合课堂表现看。

### 边界要说清楚

- **数据只在各自的浏览器里。** 老师端的数据在老师电脑的浏览器；学生端的数据在学生自己的手机或电脑浏览器。平台不上传任何内容到 GitHub 或服务器。
- **AI 整理是例外，而且由你手动触发。** 只有点“AI 整理”或“AI 精修”并确认后，当前资料正文或当前这一道题才会发送给 DeepSeek；Key 只存在本机浏览器，不进备份码、不写进网页源码。平时的拆题、分类和难度定级都在本机完成。
- **固定用桌面图标或线上地址。** 同一台电脑上，直接双击本地的 `teacher.html` / `student.html` 会按“本地文件”另存一套数据，和线上那套不互通。老师和学生都请始终用同一个网址。
- **“一人一号”是本地身份，不是服务器强制。** 任务码、汇报码经过压缩和签名，普通学生不易误用，但技术上不是加密保险箱；不要把平台当成防止破解的商业题库。
- **换设备、清理浏览器数据会丢进度。** 学生换手机前先保存汇报码，用「恢复档案」找回；老师每周在教师端「设置」里生成一次备份码，并另存到 U 盘。
- **收费仍按方案 A 手动收款。** 平台不接支付、不自动解锁；老师确认收款后，再手动发开通码或任务码。
- 教师端目前不做多教师协作；一台电脑一个教师档案。

### 单词打卡：老师发词，学生闯关

这是教师端里独立的一块，和练习卷任务并行，不占「任务」页。

1. 教师端顶部点「发布单词打卡」，或进「单词打卡」页点「发布单词任务」。
2. 选词源：**粘贴单词书**（每行一个，也可以写 `abandon 放弃`、`abandon,放弃`），或**从资料库提取**（选一篇阅读/完形/试卷，系统自动挑出生词，跳过 the、and 等虚词，最多 40 个）。
3. 平台用本机释义库自动补音标和中文；缺释义的行会标红，必须补全才能发布。预览里可以逐条改释义、删词。
4. 勾选学生、设截止日期和经验值，点「生成任务码」，仍然是一人一码。两个默认勾选值得保留：
   - **按每位学生的水平智能配词**：系统按词长、词形和抽象程度排序，从适合该学生的区间取词；每次汇报后按一次答对率自动升 / 降档。低档词更短、更具体，词量也更少。
   - **同时配本周 7 天语法课，合成一个码**：一个学生一个码，里面含本周单词任务 + 7 天语法课；学生导入一次，每天完成当天语法后自动解锁下一天，周末只交一次汇报码。
5. 学生导入后进入「单词闯关」：每出现一个新单词，页面会先自动读一遍；没听清可以点「🔊 听读音」再听，句子题也有「🔊 读句子」。题目有两种考法：**英译中选意思**，以及**语境推词意**（给一句话，让学生从上下文推断这个词的意思）。答错的词会进入最后一轮中译英重练；答对有连击，顶部进度条实时增长。先用系统英语朗读，设备没有声音时自动改用在线词典发音。
6. 学生完成后生成汇报码；老师导入后，「单词打卡」页会显示每人进度、一次答对率和高频错词，点「学情」看班级错词表。学生详情 →「任务历史」→「看作答」可以看到每一题的学生答案、正确答案和解析。

**关于“实时进度”：** 学生答题时，学生端的进度条是实时的；但老师端不会跨设备自动同步，必须等学生发回汇报码、老师导入后才更新。原因是平台没有服务器，所有数据只在本机浏览器里。这是有意的隐私选择，也让平台零服务器成本。

### 词汇书周编排：多个任务栏，接着上周往下排

1. 教师端「单词打卡」页点「词汇书编排」（在「发布单词任务」旁边）。粘贴整本单词书，一行一个，支持 `word 释义`、`word=释义`、`word,释义`；一本最多 2000 词。
2. 点「加任务栏」自行插入任务 1、2、3……，每个栏可以写栏目名、设置词数、选词策略：高频词 / 中频词 / 低频词 / 复习旧词 / 按学情自适应。系统会把本周词数分到周一到周五。
3. 难度 / 任务量可选：按学情自适应、基础巩固（少 15%）、标准进度、加难提升（多 15%）、冲刺强化（多 30%）。它会在每位学生的个人系数上再统一加减；单个任务栏的词数仍可单独改。
4. 点「预览分配」：系统读该生上一周的打卡记录、一次答对率和认知画像，按“先高频、再中频、后低频，中间穿插复习”的顺序，把书里的词排进本周五个任务栏。书不够时自动循环补词，并显示每位学生的词数和难度。
5. 勾选学生生成任务码。学生完成后回报，教师端能看到每个任务栏的完成度；全部任务栏完成后，会汇总本次任务的星级和百分比。下周再打开编排，会从这本书没排到的位置继续，并依据上周正确率自动微调难度。

### 语法打卡：60 天小营，每天 5 分钟

语法不是另开一套账号，而是教师端「语法打卡」页里独立的一条 60 天课程线，和单词打卡并行。

- **课程骨架**：以《语法透析手册》的“五大句型 + 八大成分 + 场景句”为骨架，参考叶永昌《英语阅读参考手册》“先判别功能词、再理解句意”的思路。前 30 天打基础（句子骨架、谓语动词、名词与修饰、基础从句与非谓语），后 30 天逐步加深：从句进阶（D31–38）、非谓语进阶（D39–46）、特殊结构（D47–53）、长难句与篇章（D54–60）。
- **每天 5 关**：一句“浅海侦探社”原创故事句 → 找骨架（成分标签可遮住先猜）→ 懂意思 → 用规则做 3 道题 → 隔日复习 1 道旧题 → 写一句（提交后显示参考写法，不要求一模一样）。所有故事、例句和题目均为原创，不复制书中的例句和题目。
- **老师怎么发**：教师端 →「语法打卡」→ 选本周起始日（默认“自动接上”已有进度）→ 勾选学生 →「生成 7 天打卡码」。一位学生一份码，导入后每天自动解锁一天；学完再发下一周，系统会从缺的那天继续。也可以在发布单词任务时勾选“同时配本周 7 天语法课”，把单词和语法合成一个码。
- **学生怎么用**：首页出现“60 天语法小营”卡片，显示已学天数、下一课和进度点；点“开始今天的语法课”进入。答题页改成“一题一屏”，手机上不用上下滑动找选项。完成后徽章、经验与精灵成长照常结算。
- **设计依据**：Nation 四股绳（聚焦语言形式）、Cepeda / Roediger 的间隔与提取练习、Li / Russell & Spada 的纠正性反馈、Swain 输出假说、Schmidt 注意假说，以及 Daily Grammar Practice、BBC 6 Minute Grammar、Grammar in Use、NoRedInk / Duolingo 的日练结构。教师端「语法打卡」页底部有对应的证据卡；不排名、不付费抽卡、可补学，避免把连续打卡变成压力。

### 七只神兽、解锁、融合与满月转盘

学生端的“学习伙伴”是一个可以长期养的神兽图鉴：

- **七只神兽**：小潮獭、星尾狐、云海鲸、焰羽雀、白泽、麒麟、烛龙。每只都有 4 个成长阶段（0 / 300 / 900 / 2000 成长值）。形象采用立体渐变和云气、星辉、鳞甲、角鬃等《山海经》意象，阶段越高，体型、角、鬃毛、尾巴和光环越明显。
- **解锁新神兽**：小潮獭、星尾狐、云海鲸、焰羽雀开局可选；白泽累计打卡 7 天解锁；麒麟在总经验池累计获得 1200 经验解锁；烛龙累计打卡 30 天解锁。未解锁的在图鉴里显示条件，不卖、不抽卡。
- **单独成长、随时切换**：答题、完成单词任务、喂小鱼干，都会加到“当前出战”的神兽身上。点图鉴里的神兽即可切换，其他神兽的成长值不会清零。
- **总经验栏**：账号经验结算时，其中 60% 进入总经验池。学生可以在“总经验栏”选用多少经验、拨给哪只神兽，确认后写入该神兽的成长值，记录里能看到每一笔“从总池拨给谁”。
- **终极融合**：任意两只神兽都达到终极形态（2000）后，图鉴会出现“可融合”。融合后生成一只独立的融合精灵（例如潮焰星狐、云焰鲲鹏），有单独的成长条；原来的两只都保留，随时可以切回去。
- **满月转盘**：每天打卡或完成任意任务都算一个“学习日”。连续 30 天后解锁转盘，之后每再连续 30 天可以再转一次。奖励是加权随机，包括小鱼干、成长值、满月宝箱和星辉大奖；不付费、不抽卡、不排名。
- 断签一天会重新累计连续天数，但历史学习日和已经获得的成长不会清零。

设计上参考了《Hooked》《原子习惯》《Tiny Habits》、自我决定理论、目标梯度效应和心流研究；教师端「设置」里有“正向反馈设计依据”卡片，写明每个机制对应哪条研究，以及哪些做法（付费抽卡、公开排名、损失恐惧）刻意没有采用。

### 装到手机主屏幕（PWA）

网站已经支持“像 App 一样”安装到手机桌面，不用上架应用商店：

1. **安卓**：用 Chrome / Edge 打开网站 → 右上角菜单 →「安装应用」或「添加到主屏幕」。
2. **iPhone**：用 Safari 打开网站 → 底部「分享」→「添加到主屏幕」。
3. **微信里**：点右上角「…」→「在浏览器打开」，再按上面的步骤安装。
4. 装好后桌面会出现「顺势」图标，打开时全屏显示，没有浏览器地址栏。
5. 第一次打开后会自动缓存页面；断网时还能打开上一次看过的内容（数据仍以浏览器本地为准）。

四个页面（主页、学生端、教师端、工作台）共用同一套缓存。更新网站后，联网打开会自动取新版本，不需要重装。

### 微信小程序：现在到哪一步

**现状：** 网站是 GitHub Pages 静态站，没有服务器。微信小程序不能直接“套”这个网址，必须满足微信的硬性要求：

- 个人主体的小程序**不能使用 `web-view`，也不能配置业务域名**（微信官方限制，截至 2025 年未变）；
- 业务域名必须是**自己名下的、已完成 ICP 备案的 HTTPS 域名**；
- `github.io` 不是自己的域名、无法备案，所以不能直接作为业务域名；
- 还需要一个服务器（或微信云开发）来放网页和校验文件。

因此有三条路：

| 路线 | 需要什么 | 现在能不能做 |
| --- | --- | --- |
| A. PWA 加到桌面 | 无 | **已做好**，推荐先用这个 |
| B. 小程序套壳（web-view） | 企业/组织主体、备案域名、服务器 | 模板已放在 `miniprogram/`，填 AppID 和域名后可用 |
| C. 原生小程序 | 个人主体即可，但要重写四个页面 | 工作量大，且教育类目审核可能需要资质 |

`miniprogram/` 里是一个四入口的套壳模板：首页四个按钮，分别打开主页、学生端、教师端、组卷工作台。它不是已经上线的小程序，只是把“以后有主体和域名时怎么接”准备好。具体步骤见 `miniprogram/README.md`。

## 教师工作台怎么用

工作台在主页页脚的「教师工作台」入口，也可以直接访问上面的工作台地址。手机浏览器同样可以使用，上传、生成、预览和下载都做了窄屏适配。

**资料只保存在这台电脑（或这台手机）的浏览器里**（IndexedDB 本机数据库），不会上传到 GitHub、网盘或任何服务器。换设备、换浏览器、清理浏览器站点数据后，资料不会自动跟过去，所以请定期备份。

### 上传与整理

1. 打开「上传资料」，把 Word（.docx）、PDF、TXT、Markdown、图片（PNG/JPG）拖进去，或直接粘贴题目文字。
2. 有文字层的 PDF 和 Word 会直接提取文字；扫描版 PDF 和图片会走本机 OCR（Tesseract，支持英文 + 简体中文），图片识别后再入库。
3. 页面会按试卷的部分标题、题号、选项和文章结构自动判断题型（单选、完形填空、阅读理解、五选五/七选五、语法填空（含短文填空、短文填词、首字母填空、选词填空）、书面表达、听力等）和年级，把综合卷拆成多个题组，阅读按 A/B/C/D/E 篇拆开。
4. 每道题按词汇难度、句长、从句、非谓语、被动语态、设问方式和题型给出 1–10 级难度；完形填空和语法填空还会给每个空单独定级，并显示 ★–★★★★★ 星级。
5. 入库前会自动清理重复页眉页脚、页码、题库网址、扫描软件水印、卷面“第X部分”标记和符号噪点，生成练习时还会再清一次。
6. 原文件始终保留，可下载；系统同时生成加水印的整理版 Word 并入库。
7. 识别不准时，点资料卡上的「修改」，手动改题型、年级、标题、正文或答案，保存后会重新拆题。
8. 排版还是乱（题号、选项、大题标题粘成一团）时，点资料卡上的「豆包精排」：复制提示词到豆包，让它只调整换行和分段，再把整理稿整段粘回来。系统会按新稿一道一道重新分题，原始文件仍保留。
9. 豆包精排和日常导入遇到的新大题叫法，会自动记进「设置 → 题型识别库」；下次同类卷子直接能认出来，也可以手动添加别名。

### 逐题编辑：看得见每一道题

入库后，资料卡和练习卷卡片上都有「逐题编辑」按钮（铅笔图标）。打开后可以：

- 逐题查看识别出来的题干、选项、答案、解析和难度；
- 直接修改任意一道题，改完点「保存全部修改」写回本机数据库；
- 把明显无关的杂物题标记删除，保存后才会真正移除；
- 每道题右侧有一个「AI 精修」按钮，只把这一道题发给 DeepSeek，修 OCR 断行、选项排版和页眉残留。发送前会弹确认并显示预估费用，点“取消”就不会产生任何调用。

### AI 整理与费用：花在哪里，一目了然

组卷工作台的「设置 → AI 整理与消耗」和教师端的「设置 → AI 直连」共用同一份本机 Key（`localStorage`，不进入备份、不写进源码）。

- **整份资料整理**：资料卡上的闪光图标会调用 DeepSeek，删除页眉页脚、页码、学校名、网站广告、水印和考试须知，重新判断题型与年级，并整理题目排版。发送前弹窗显示正文长度、预计 tokens 和预估金额；正文最多发送前 5000 字，避免一份长卷一次花太多。
- **单题精修**：只发送当前这一道题，输出限制 360 tokens，适合修零星的 OCR 错误。
- **用量账本**：教师端「设置」和工作台都会显示累计输入 / 输出 tokens、调用次数、预估人民币金额，以及**按来源永久累计**的消耗表（例如单词打卡、周任务、资料库 · AI 整理、资料库 · 单题精修、AI 分析）：每个来源的调用次数、tokens 和金额，不会因为“最近 200 条明细”滚动清除而丢失。费用按 DeepSeek Flash 高峰价保守估算（输入 ¥2.2 / 百万 tokens，输出 ¥8.6 / 百万 tokens），实际以 DeepSeek 账单为准。
- **不会偷偷调用**：只有点“AI 整理”或“AI 精修”并确认后才会联网；平时的拆题、分类、难度定级都在本机完成，零费用。

### 生成每日练习

在「每日练习」输入指令，例如：

```text
今日练习 高一 单选5道 阅读理解2篇 语法填空1篇 难度5-7
随机 10 道单选 难度4
今日练习 高三 完形填空1篇 五选五1篇 书面表达1篇
```

系统会按年级、题型和难度随机抽题，排成正式试卷样式：日期 + 试卷标题、姓名/班级/得分栏、分题型大题、选项、阅读篇目、作文横线，后面附参考答案与解析、词汇背诵表、默写表。中文字体用黑体，英文用 Arial。

资料库和每日练习都有「全部 / 初中 / 高中」三档切换，指令里写「初中」「高中」「高一」等字眼也会自动切到对应题库。初中卷不会拿高中题凑数，反之亦然。

可以「换一组」重新抽，下载 Word，或点「打印 / PDF」后在打印窗口选择「另存为 PDF」。生成的练习卷也能存进资料库，方便以后复用。

点「长难句」会从本份练习的阅读、完形、五选五里挑出完整长句，生成「原句 + 分析横线 + 译文横线」的练习纸。

### 解析与词表

- 本地规则会给出答案、考点、难度、基础答题思路，并生成三列词表（英文 / KK 音标 / 中文）和默写表。词表会按年级筛词：去掉 the、does 这类基础词，只保留略高于当前水平、且在本份练习里出现的词，一份 59 题的卷子通常收 30–40 个词。
- 需要范本级别的「语篇导读 + 逐项排除 + 长难句分析 + 熟词生义」时，用「豆包解析」：复制提示词到豆包，生成后把结果粘贴回来应用即可。
- 「豆包词表」同理，用来补齐本地词库没有收录的音标和语境释义。
- 工作台不会自动上传试卷，也不保存豆包账号信息；所有复制粘贴都在本机完成。静态网页里不写 API Key，避免泄露。

### 备份与恢复

- 「设置」→「导出备份」会下载一个 ZIP，里面有全部原文件、整理版、题组、练习卷和 `library.json`。
- 「设置」→「U 盘工作区」可以把常插着的 U 盘设为中转站：选中一次后，下载的 Word 和导出的备份会自动复制一份到 U 盘；也可以点「备份到 U 盘」立刻存一份。需要 Chrome 或 Edge 桌面版。
- 换电脑或清理浏览器数据前，先导出 ZIP；在新环境打开工作台，用「导入备份」选回这个 ZIP 即可恢复。
- 建议每周备份一次，放在网盘或移动硬盘里。
- 手机和电脑的浏览器数据互不相通。如果要在手机上看电脑里的资料，先在电脑导出备份，再把 ZIP 传到手机导入。

### 已知限制

- OCR 是机器识别，题号、引号和易混字母（l/I、0/O）可能出错，入库后请核对一遍。
- 整本一百多页的扫描卷不建议一次 OCR；在「设置」里限制页数，或只上传需要用的几页。
- Word 只能提取文字，复杂表格、图片和原版排版会简化；原文件仍完整保留。旧版 .doc 会完整存档，但不能自动提取文字。
- 题型识别是关键词加文本特征的自动判断，冷门命名可能需要手动改一次。
- 本地词库没有收录的词，音标或中文会显示「—」，用「豆包词表」补齐即可。
- Word 里的水印是平铺文字，打印和 PDF 效果最稳定；不同版本 Word 的渲染可能略有差异。

## 注意事项

- 不要删除或截断 `index.html` 中的 `data:image/png;base64,...` 字符串，那是页面里的微信二维码。
- 个人主页是公开的，邮箱和微信二维码会对外可见；教师工作台里的资料只存在你自己的浏览器里，不会公开。
- 不要把真实学生资料、试卷原文件提交进 git 仓库；仓库里只放网页代码和 `vendor/` 依赖。
- 首次印刷主页二维码前，建议先用手机相机和微信各扫一次确认效果。
- GitHub Pages 国内偶有访问缓慢；如果以后大量印刷宣传物料，建议绑定自己的域名，换服务器时二维码不用重印。
